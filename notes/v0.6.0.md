Download `powerkit.exe` below, or choose **Install update** in the tray menu if PowerKit is already running.

### New

- **Installed apps.** PowerKit now shows up in Settings > Apps > Installed apps. Uninstalling it removes its startup entry, Start menu shortcut, Explorer menu and PowerShell profile lines, and asks before deleting your settings. `powerkit --uninstall` does the same. A portable copy stays out of Installed apps.
- **Start menu and search.** PowerKit can be found in Start and Windows search. Opening it from there while it runs opens the settings.
- **Find a setting.** Type in the box on the Dashboard to see every matching setting from every page, and change it right there.
- **Back up your settings.** General has Export settings, Import settings, Reset all settings and a button that opens the log folder. Every utility's page ends with Restore defaults. Resetting asks first.
- **Dark mode everywhere.** The list windows (Hosts, Environment Variables, Workspaces, File Locksmith, Screenshots, Image Resizer), Quick Notes, PowerRename and Registry Preview follow the app theme.
- **Tray menu.** The utility switches moved into a Utilities submenu, and What's new opens these notes.

### Utilities

- **Peek** shows what is inside more files: the first page of a PDF with its page count, SVG pictures, and the same preview Explorer shows for videos, documents and music.
- **FancyZones** puts an app's new windows in the zone its last window went to. It can also take over Win+Left and Win+Right to move windows between zones (off by default). Zones flash briefly when you switch layouts, the Grid template makes exactly the number of zones you ask for, and zones keep their names when you resize them.
- **Workspaces** can be renamed, and Desktop shortcut puts a shortcut on the desktop that launches one. When capturing, it tells you which windows it left out.
- **Quick Accent** no longer opens when you hold a letter and press Space in a game or another full-screen window. A setting turns this off if you want it back.
- **Clipboard History** keeps pictures as well as text, up to 20 until PowerKit closes.
- **Hosts File Editor** keeps the last ten versions of the file, named by date, in a `hosts-backups` folder.

### Faster and safer

- Clicks and typing no longer wait on PowerKit while it works. Pasting, reading text from pictures and saving screenshots happen in the background, and Zoom It's live zoom does far less work per frame.
- Updates are checked before they are installed: the download must match the checksum GitHub publishes for it, or it is refused.
