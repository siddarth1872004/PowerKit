The first release of PowerKit: 35 utilities for Windows 10 and 11 in one small program that runs in the tray.

Download `powerkit.exe` below and run it. There is no installer. Click the tray icon to open the settings, and turn utilities on or off on the Dashboard. Later releases can be installed from the tray menu with **Install update**.

### What's in it

- **Windows:** FancyZones, Window Tiling, Workspaces, Always On Top, Crop and Lock, Grab and Move and Window Hopper.
- **Keyboard and launching:** PowerKit Run, Keyboard Manager, Shortcut Guide, Peek, the File Explorer add-ons, New+ and Command Not Found for PowerShell.
- **Clipboard and text:** Clipboard History (text and pictures), Advanced Paste, Quick Accent, Text Extractor and Quick Notes.
- **Screen:** Color Picker, Screen Ruler, ZoomIt, Screenshot, Screen Recorder, Mouse utilities, Light Switch and Power Display.
- **Files and system:** PowerRename, Image Resizer, File Locksmith, Hosts File Editor, Environment Variables, Registry Preview, Awake and Power Plan Switcher.

The README lists every utility with its shortcuts.

### Good to know

- Find any setting by typing in the box on the Dashboard. Export settings and Import settings under General move your setup to another PC.
- Every window follows the app theme, light or dark.
- Put an empty file named `portable` next to `powerkit.exe` to keep its settings beside it, for example on a USB stick.
- PowerKit shows up in Start, Windows search and Installed apps. Uninstalling it removes everything it set up in Windows and asks before deleting your settings.
- Updates are checked against the checksum GitHub publishes before they are installed.
