PowerKit v

utilities for Windows in one small program that runs in the tray: window zones, a launcher, clipboard history, a color picker, screen tools and more.

Download powerkit.exe Windows 10 and 11 · no installer · source on GitHub · MIT license

What it is

  • One background program written in Rust. Utilities you leave off do nothing.
  • No account and no telemetry. The only thing it fetches is the daily update check.
  • Updates itself, checking each download against the checksum on GitHub first.
  • Each utility has a short walkthrough in the settings, drawn with your own shortcuts.

Getting started

  1. Download and run powerkit.exe. It goes to the notification area and can add itself to Start and Windows search.
  2. Click the tray icon to open the settings. Turn utilities on or off on the Dashboard, or type in its search box to find any setting.
  3. When a new release is out, choose Install update in the tray menu.

Command line

powerkit --workspace "Work"   # launch a saved workspace
powerkit --rename *.jpg       # PowerRename these files
powerkit --hosts              # Hosts File Editor
powerkit --unlock C:\file.txt # which programs are using it
powerkit --quit               # close the running PowerKit

Questions

Can I keep it on a USB stick?
Yes. Put an empty file named portable next to powerkit.exe and its settings go in a data folder beside it.
Does it need administrator rights?
No. Windows asks only when you save the hosts file or system environment variables, and once when you turn on the Windows 11 context menu entries.
Can I move my settings to another PC?
Yes. Use Export settings and Import settings under General in the settings.
How do I remove it?
Uninstall it from Settings > Apps > Installed apps. It undoes what it set up in Windows and asks before deleting your settings.
Is it related to Microsoft PowerToys?
No. PowerKit is an independent project with its own code.
