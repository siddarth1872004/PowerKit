Get started

No installer and nothing to configure first.

Download and run

Run powerkit.exe. PowerKit lives in the notification area and can show up in Start and Windows search.

Pick your utilities

Click the tray icon for settings. Switch utilities on or off on the Dashboard, or find any setting by typing a word.

Stay current

PowerKit looks for a new release once a day. Choose Install update in the tray menu and it updates and restarts.

From the command line

Every window can be opened from a script or a shortcut.

powerkit --workspace "Work"   # bring back a saved workspace
powerkit --rename *.jpg       # PowerRename these files
powerkit --hosts              # Hosts File Editor
powerkit --unlock C:\file.txt # which programs are using it
powerkit --quit               # ask the running PowerKit to exit

Questions

 

Can I keep it on a USB stick?

Yes. Put an empty file named portable next to powerkit.exe and settings are kept in a data folder beside it instead of in your profile.

Does it need administrator rights?

No. Windows asks only when you save the hosts file or system environment variables, and once when you turn on the Windows 11 context menu entries.

Can I move my settings to another PC?

Yes. Under General in the settings, Export settings saves them to a file and Import settings reads that file on the other PC.

How do I remove it?

Uninstall PowerKit from Settings > Apps > Installed apps. It undoes what it set up in Windows and asks before deleting your settings.

Is it related to Microsoft PowerToys?

No. PowerKit is an independent project with its own code. It covers similar ground, in a single small program.
